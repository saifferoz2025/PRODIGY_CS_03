# 📌 3: Password Complexity Checker

## 📖 Introduction
A tool that checks the **strength of a password** by analyzing its length, character diversity, and use of digits and symbols. It helps users build stronger and more secure passwords.

## 🎯 Purpose & Use Cases
This tool raises awareness about the importance of secure password practices. It can be used for:
- Personal password checking
- Training users in cybersecurity basics
- Demonstrating regex and validation in Python

## ⚙️ Features
- ✅ Checks password length
- 🔠 Verifies uppercase and lowercase letters
- 🔢 Detects digits
- 🔣 Identifies special symbols
- 📊 Gives feedback: Weak, Medium, or Strong
- 🖥️ Works in both console and GUI mode

## 🛠️ Tools & Technologies Used
- Python 3
- Regex (re module)
- Tkinter for GUI

## 🌟 Benefits
- Encourages stronger password habits
- Provides instant feedback to users
- Teaches regex and input validation concepts

## ⚠️ Ethical Note
This tool is **educational** and helps improve personal security habits. It does not store or transmit passwords.
